# ⚔️🐧 Terminal Bash Arena 🐧⚔️

### *Stealth. Attack. Survive.* 💀💻

🔥 Welcome to the **Terminal Bash Arena**!

A free-for-all Linux showdown where

* speed ⚡,
* strategy 🧠,
* and survival skills 🛡️

*make all the **difference**!*

## 🎯 The Mission

SSH into the Raspberry Pi 🖥️ and use ONLY basic Linux shell commands to:

* ⚔️ Attack your classmates
* 🛡️ Defend your own folder
* 👻 Cover your tracks
* 🏆 Score as many points as possible

## 🚪 Entering the Arena

Once you **SSH** into the **Raspberry Pi** 🥧, navigate to your personal directory using:

```bash
cd ./<class-date>/<class-lastname-firstname>
```

From that moment on…
🔥 **The Battle is On** 🔥

## 🧰 Allowed Commands

* `cd`
* `ls`
* `mkdir`
* `rm`
* `echo`
* `chmod`
* `chattr`
* `sudo`
* `ps`
* `grep`
* `kill`
* `>`
* `>>`
* `|`

## ⚔️ How to Attack

An attack consists of writing your:

```text
lastname-firstname
```

inside the files located in other students' folders 📂

💡 The more times your name appears in your opponents' files, the more points you rack up!

#### Example:

```bash
echo homer jay simpson >> ../<other-student-folder>/file.txt
```

## 🧠 Stealth Mode 👻

### ⚠️ Keep Your Attacks Hidden!

If a file name makes it too obvious who the attacker is 😬 (e.g., `.smith`, `john.txt`, `smith_attack`, etc.)

➡️ You will hit a penalty.

## 🏆 Scoring System

### ⚔️ Offense

Files

* Inappropriate file name ❌ >> 0 pts
* Standard file 📄 >> +1 pt
* Sneaky dotfile 👻 (`.filename`) >> +2 pts
* Writing your name in an opponent's **.flag** 🚩 >> +3 pts

📌 Every single occurrence of your name counts as a successful hit.

## 🛡️ Defense

Every file left in your personal folder will drag down your final score 😵

* Script files (with `.sh` extension) >> 0 pts
* Standard file 📄 >> -1 pt
* Dotfile 👻 >> -2 pts
* Missing or compromised **.flag** 🚩 (meaning it contains an opponent's name) >> -5 pts

### ⚠️ Yes, hidden files count too!

## 🚫 Rules of Engagement

* ❌ Do NOT delete directories
* ❌ Do NOT use offensive or inappropriate names
* ❌ Do NOT leave the game area (sandbox)
* ❌ Do NOT sabotage the system

📌 All file names will be reviewed by the instructor.

If deemed invalid or inappropriate, those attacks will NOT be counted.

## 🏅 Leaderboard

Your final score will be calculated as:

```text
Offense - Defense
```

🔥 The top players will also take home a bonus for effort, speed, and strategy!

## 🐧 One Last Tip

*Keep a close eye on your own folder…* 👀
*Because while you are busy hunting someone down…*

*…someone else might be wiping you out* 💀

# ⚔️🐧 Terminal Bash Arena 🐧⚔️

### *Stealth. Attack. Survive.* 💀💻

🔥 Benvenuti nella **Terminal Bash Arena**!

Una sfida Linux tutti contro tutti dove

* velocità ⚡,
* strategia 🧠
* e capacità di sopravvivenza 🛡️

*faranno la **differenza**!*

## 🎯 Obiettivo

Entrare nel Raspberry tramite SSH 🖥️ ed usare SOLO i comandi base della shell Linux per:

* ⚔️ attaccare gli altri studenti
* 🛡️ difendere la propria cartella
* 👻 nascondere le proprie tracce
* 🏆 ottenere il punteggio più alto possibile


## 🚪 Accesso all’Arena

Dopo l’accesso **SSH** al **Raspberry Pi** 🥧 dovrete entrare nella vostra directory personale usando:

```bash
cd ./<classe-data>/<classe-cognome-nome>
```

Da quel momento…
🔥 **La Battaglia avrà Inizio** 🔥

## 🧰 Comandi Consentiti

* `cd`
* `ls`
* `mkdir`
* `rm`
* `echo`
* `chmod`
* `chattr`
* `sudo`
* `ps`
* `grep`
* `kill`
* `>`
* `>>`
* `|`

## ⚔️ Come Attaccare

Un attacco consiste nello scrivere il proprio:

```text
cognome-nome
```

all’interno dei file presenti nelle cartelle degli altri studenti 📂

💡 Più volte compare il vostro nome nei file avversari, più punti otterrete!

#### Esempio:

```bash
echo homer jay simpson >> ../<other-student-folder>/file.txt
```

## 🧠 Stealth Mode 👻

### ⚠️ Gli attacchi devono essere Nascosti!

Se il nome del file è troppo riconducibile all’attaccante 😬 (esempio: `.rossi`, `mario.txt`, `rossi_attack` ecc.)

➡️ verrà applicata una penalità.


## 🏆 Griglia Punteggi

### ⚔️ Attacco

file

* Nome file NON appropriato ❌ >> 0 pt
* File appropriato 📄 >> +1 pt
* Dotfile appropriato 👻 (`.nomefile`) >> +2 pt
* scrittura del proprio nome nel **.flag** 🚩 avversario >> +3pt

📌 Ogni occorrenza del vostro nome conta come un attacco.


## 🛡️ Difesa

Ogni file presente nella vostra cartella personale abbasserà il vostro punteggio finale 😵

* file script (con estensione `.sh`) >> 0pt
* File normale 📄 >> -1 pt
* Dotfile 👻 >> -2 pt
* **.flag** 🚩 mancante o compromesso (ovvero contenente anche il nome di avversari) >> -5pt

### ⚠️ Anche i file nascosti contano!

## 🚫 Attenzione

* ❌ Non cancellare cartelle
* ❌ Non usare nomi volgari o non appropriati
* ❌ Non uscire dall’area di gioco
* ❌ Non sabotare il sistema

📌 I nomi dei file saranno valutati dal docente.

Se considerati non appropriati o non validi, gli attacchi NON verranno conteggiati.

## 🏅 Classifica Finale

Il punteggio totale sarà dato da:

```text
Attacco - Difesa
```

🔥 I giocatori con il punteggio più alto verranno premiati per impegno, rapidità e strategia!

## 🐧 Consiglio Finale

*Controllate spesso la vostra cartella…* 👀
*Perché mentre state attaccando qualcuno…*
